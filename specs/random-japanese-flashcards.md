# Random Japanese Flashcards

## Behavior

- On load, show one **random** word from the bundled list.
- **Next card** chooses another random word; the same word is **not** shown twice in a row (when the list has more than one entry).
- Words are **kana-only** strings (hiragana, katakana, and prolonged sound mark), suitable for reading practice.

## Word list

- Generated by `scripts/generate-kana-words.mjs` from [Hermit Dave’s Japanese frequency list](https://github.com/hermitdave/FrequencyWords) (MIT), keeping kana-only tokens of length ≥ 2 in corpus frequency order, deduplicated, until the target count (currently 3500) is reached.
- The JSON artifact is committed as `src/random-japanese-flashcards/words.json` so builds do not require network access.

## Implementation notes

- Random index selection lives in `pick.ts` (pure functions, injectable RNG for tests).
- UI state is the current index into the readonly word array.
