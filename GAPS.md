# Gaps and follow-ups

- **Random Japanese Flashcards**: Optional next steps include English gloss / flip-to-reveal meaning and deeper spaced-repetition scheduling (beyond starring). File new `bd` issues if you start work on those.
- **Advanced Paster**: The UI could be updated to feel more modern and premium (e.g. glassmorphism, animations).
- **Advanced Paster**: LaTeX parsing has been upgraded to use Temml for rendering MathML in the HTML output, but Markdown/Plaintext still use the best-effort Unicode translation. Fully aligning all outputs could be a future improvement.
- **Advanced Paster**: `\mathbf` wrappers are stripped before MathML/Unicode conversion; other font macros that Temml still renders (e.g. `\boldsymbol`, `\mathrm`) may need the same treatment if they produce unhelpful styling.
- **Advanced Paster**: `latexToText` keeps LaTeX grouping braces, so a Wikipedia formula such as `{\text{Speedup}}={\frac {a}{b}}` yields `{Speedup}={(a)/(b)}` in the Markdown and Plaintext outputs. The braces cannot simply be dropped — `\mathbb{R} \setminus {0}` relies on them for set notation — so distinguishing grouping from notation needs a real parse. The MathML output is unaffected.
- **Advanced Paster**: `lib/dom.ts` now parses pasted HTML with the browser parser. The remaining regex-based tag walking in `converter.ts` (`findMatchingSpanEnd`, `processDisplayStyleMath`) could move onto the same foundation; it is kept for now because it also carries the `findFallbackSuffix` deduplication of plain-text math that precedes a formula.
- **Mermaid Editor**: Future enhancements could include pan/zoom controls for large diagrams, UI controls for dynamically configuring diagram layout spacing (`rankSpacing`, `nodeSpacing`, orientation, and `wrappingWidth` slider) without manual front matter editing, multi-line edge label wrapping and alignment, custom CSS/theme variable styling, direct `.svg` / `.png` file download buttons, and persisting diagram drafts to `localStorage`.
- **Warhammer Pairing Solver**: Potential follow-ups include supporting custom team draft sizes (e.g. 5v5 or 6v6 regional tournament formats), offloading tree solving to a dedicated Web Worker for background processing on low-power mobile devices, and exporting finalized draft pairings and scorecard to PDF / shareable image.
- **Kanji Battle**: Future follow-ups include Apple Pencil double-tap shortcut integration to quickly clear ink or toggle hints, pressure-sensitive brush stroke thickness for stylus users, a left-handed layout mode flipping the reference sidebar to the right edge, adding unboxing sound effects and audio pronunciations, duplicate trading / crafting mechanics for extra minifigure copies, special foil/rare blind box tiers, higher grade levels (Years 4-6 elementary kanji and junior high kanji), deeper handwriting OCR classification models for cursive/rapid kana variants in freeform mode, and daily streak multipliers for scoring.
- **Agent Host Protocol UI**: Upstream releases of `@toumorokoshi/agent-host-protocol-ui` can be updated by bumping the package version in `package.json`. Follow-up improvements could include integrating automated version check notifications or offline cache manifest generation.
